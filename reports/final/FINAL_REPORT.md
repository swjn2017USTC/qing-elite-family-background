# FINAL REPORT — 清代官僚精英的家世与仕进：一日常量级 micro-study（v0.1-one-day）

**研究问题**：清代（1644–1820）官僚体系中，家庭政治—教育资本是否随官位接近权力中心而系统性变化？
地方基层对照使用 CGED-Q JSL 的 1760–1798 截面。

**本文的组织纪律**：四个层次严格分开——**数据事实（§2）**、**统计关联（§3）**、**史学解释（§4）**、**局限（§5）**。
§3 的数字不允许直接搬进 §4；§4 的每一句都以"假说"标记。

---

## 1. 一句话结论

在这批史料里，**家世信息的"可见度"随官位层级急剧变化**（中枢 47–78% → 府县 0.96%），
而**在"有家世记录"的人内部，中枢与府县的祖先任官比例都约 55%，B/C 层反而只有 14–30%**。
这两条都只是**描述与关联**；它们同时受史料生成机制支配，**不能读作家世结构本身的因果差异**。

## 4. 史学解释（假说，非结论）

> 以下全部是**解释性假说**，需要独立史料（族谱、题名录、履历档）验证后才能进入史学论断。

- **H1 史料可见性梯度**：中枢人物的家世被记录的概率远高于府县官员（52–78% vs 0.96%），
  这本身与清代传记书写传统（国史馆列传、碑传、地方志）只覆盖高官有关。若成立，则任何"家世—官位"梯度的解读都必须先扣除该书写的选择机制。
- **H2 "自致"与"承袭"并存**：A 层中 83% 的三代齐全者其三代皆无功名/任官（n=6，极小样本），
  与清代高层确有相当比例出自非官宦家庭这一常见判断方向一致；但样本量不足以支撑比例陈述。
- **H3 B/C 层的"中间结构"**：B（六部尚侍）与 C（督抚）的祖先任官比例低于 A 与 D，可能反映
  该两层的任官路径更依赖科举与铨选而非家族荫叙；同样需要族谱一级材料才能验证。
- **H4 区域**：`jiangnan_core`（44.8%）与其它省份（44.4%）无差异——本数据**不支持**"江南籍家世结构不同"的假说（但也可能只是功效不足）。

## 5. 局限（必须随结论一起引用）

1. **资料可见性偏差**：家世记录的存在与否与官位高度强相关（§2.2、§2.4）。所有比例都建立在一个非随机可见的子集上；
   1 代已知者 50.8% 有任官祖先 vs 3 代齐全者 14.5% 的**反直觉**模式，正说明"被记录"本身是一种选择。**未知不等于平民。**
2. **高低层 coverage 差异极大**：A 层 47–78%，D 层 0.96%。D 层 99.0% 三槽位全未知，
   其"有记录者"是强选择样本（有名到被 CBDB 收录或入《清史稿》）；**D 层只能用于 coverage benchmark，不能用于家世比较。**
3. **CGED-Q 时间窗**：D 层仅覆盖 **1760–1798** 且只有 16 个季节年（春/夏/秋，无冬）。
   因此 A/B/C/D 的共同分析被限定在 1760–1798；1644–1820 只做 A/B/C 长时段趋势，**不可外推 D 层**。
4. **entity linkage 风险**：JSL↔CBDB 高置信链接仅 **18.4%**（放宽到"姓名唯一"为 46.3%）；
   16.3% 的 JSL 人物无姓（旗人称名不举姓）结构上无法按姓名匹配；总体内 1,168 个姓名对应多人；871 个 CBDB 人被多个 JSL 人命中。
   RapidFuzz 仅召回候选、绝不自动认定同一人（`match_status` 无 "accepted"）。
5. **LLM 只抽事实字段、不决定寒门分类**：模型输出仅 `name/degree/office/evidence`，且证据必须逐字命中原文窗口才被接受（否则置 unknown）；
   全部寒门/官宦判定由 `config/research.yaml` 的 Python 规则完成。LLM 引入的是**可见性扩展**（把文本里的家世变成结构化事实），不是判定标准。
6. **结果不能自动解释成因果关系**：本设计无外生变动、无对照组，覆盖率与指标同时受史料生成机制驱动；
   所有差异只能表述为 association / selection / composition。P07 审计进一步证明现有样本**不足以**支持多变量控制
   （含旗籍项的模型因完全分离不可估计）。

其他已披露局限：`ancestor_high_official` 因官名词表不含中级官而系统性偏低（30/54 条 LLM 官职无法归层）；
`strict_commoner_3g` 分层分母仅 1–24 人；旗籍各组 ≤47 人且 610 人旗籍未知；A 层 1 例籍贯不一致（張百齡）待人工裁决；
degree accuracy 在 pilot 中不可测（原文本就不载功名）。
