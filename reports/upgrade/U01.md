## 6. 影响研究结论的方法决策

1. **四态取代二值**：`positive / explicit_negative / unknown / conflict`；空字段只能是 `unknown`。v0.1 的 `ancestor_official_any=0`（387 人）在新框架下不存在由缺失推出的 0（primary 中 `documented_ancestor_official_any==0` 为 0 行，出现 0 必须有逐槽位的明确否定证据）。
2. **结构化来源的引文语义**：CBDB 结构化记录没有连续原文，`positive` 的 `quote` 取该字段的来源字符串（如官职串），`source_locator` 记录 `source_title|textid|pages`，offset 留空；字符级 span 规则只对文本来源（《清史稿》窗口）生效。这是一条明示的口径，不是放宽。
3. **LLM 引文仍是槽位级**：v0.1 一个 quote 支持整个槽位（U00-05、计划 §5），迁移只能照录；按字段独立 span 是 U05 的验收项，U01 不掩盖这一点（`confidence`、`extraction_run_id` 原样保留）。
4. **resolution_status 直接继承 v0.1 链接标签**（`CBDB` 直连或 `linkage_confidence=='high'` 记为 resolved），U01 不做任何链接；U02 用 gold + 概率链接替换该列，primary 覆盖面随之扩大。
5. **primary 与 legacy 物理隔离**：legacy 指标只以 `legacy_` 前缀存在于独立表，schema `strict=True` + 显式检查禁止其进入 primary。
6. **review pending 阻断**：40 位 pilot 人物的全部断言标记 `pending`，`select_primary_assertions()` 先剔除；`build_primary_indicators()` 再对 pending/conflict/unresolved 做防御性拒绝（双重保险）。
